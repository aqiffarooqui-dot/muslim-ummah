# Muslim Ummah

A modern Islamic companion mobile app built with Expo and React Native.

## Features

- Quran
- Hadith
- Prayer times
- Daily Ayah
- Daily Dua
- Bookmarks and favorites
- Modern cinematic Islamic UI

## Run locally

npm install
npm start

## Web Build

npm run build:web

## Platforms

The primary target is Android and iOS.

The web version is maintained separately for preview purposes.
